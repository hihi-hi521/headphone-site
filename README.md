# AURALIS ARC ONE

基于提供的 15 秒耳机影片制作的四章式产品展示网站。

## 打开

直接在浏览器中打开本目录的 `index.html`。不需要安装依赖、不需要启动服务，页面不依赖外部网络。

分享时请发送整个 `headphone-site` 文件夹，或使用同级目录的 ZIP 完整包。不要只移动 HTML 文件。

## 交互

- 向下滚动、向上轻扫、下方向键或点击右箭头：播放至下一章。
- 向上滚动、向下轻扫、上方向键或点击左箭头：返回上一章。
- 顶部导航、底部四段章节线：进入指定章节。
- 左侧弧形箭头：重新播放开场。
- 顶部扬声器：开启或关闭分镜播放时的原片音轨，默认静音。
- “完整影片”：播放原始视频，支持原生视频控件、全屏与进度拖动。
- 最后一章“认识 ARC ONE”：查看产品概念介绍。
- 系统启用“减少动态效果”后，以静态停靠图切换。
- 如素材加载失败，可重试或切换静态版本。

## 素材与停靠点

原始文件：`minimax-h3-1793200997624039.mp4`。

网站中的 `assets/arc-one-film.mp4` 为原片的逐字节副本，没有修改原始文件，没有去除原片标记。

章节音轨使用 `assets/arc-one-audio.m4a`，从原片无损分离，便于在移动端快速开始和暂停。

影片实际参数：1344 × 768，24fps，362 帧，约 15.083 秒，附原片音轨。

目前本次附件只有视频，未收到独立分类的停顿图，因此使用从实际成片核对并抽取的画面：

| 章节 | 零基帧号 | 图片文件 | 时间 |
| --- | ---: | --- | ---: |
| 01 初见 | 63 | frame_0064.jpg | 2.625 秒 |
| 02 静界 | 168 | frame_0169.jpg | 7.000 秒 |
| 03 共振 | 240 | frame_0241.jpg | 10.000 秒 |
| 04 纯粹 | 358 | frame_0359.jpg | 14.917 秒 |

对应停顿图也保存在 `assets/pause-01.jpg` 至 `pause-04.jpg`。

完整帧序列位于 `assets/frames/`，共 362 张原生分辨率 JPEG，约 19.34 MiB。使用全量预加载，并让浏览器管理解码缓存，避免在移动端持有数百张高分辨率位图。

## 修改

- `index.html`：产品文案、章节与弹窗结构。
- `styles.css`：视觉样式、布局和屏幕适配。
- `script.js` 顶部 `CONFIG`：帧数、帧率、四个停靠点、触控板防惯性设置。
- `transitionScale`：数值越大，章节播放越慢；默认 `1` 保持原片时间比例。
- 替换停靠帧时，应同时更新 `CONFIG.stations` 和相应静态预览图。

此版本不包含电商、预约提交或后端服务。ARC ONE 为视觉概念，并非在售商品；页面没有宣称未经核实的降噪、续航等性能数据。

## 验证说明

已验证桌面 1440 × 900、宽屏 1920 × 1080、手机 390 × 844 与 360 × 640，以及平板和手机横屏布局。四章切换、反向播放、触控滑动、触控板惯性保护、完整影片、产品弹窗、减少动态效果及无 JavaScript 降级均已检查。

音轨的定位、播放与定格暂停已通过静音输出测试；当前测试环境的浏览器在实际输出声音时，独立音频页面也存在音频时钟停滞，因此未能验收扬声器实际出声。首次打开时请点击右上角声音按钮试听。
